CLAN WARS FOR UBUNTU — NATIVE STARTER PREVIEW

Use Ubuntu 24.04 LTS Desktop on an x86-64 PC with native Steam and
TRIBES 3: Rivals installed. This preview uses separate application
files, lobby identity, game staging and Proton prefix.

1. Run the .run installer from a terminal. It opens the native Starter.
   To reopen it later, run "Start Clan Wars Ubuntu.sh" in the install
   folder shown by the installer.
2. Open Steam Setup in the Starter. In Steam, enable Proton under
   TRIBES 3: Rivals > Properties > Compatibility. Copy the complete
   launch option into Properties > General > Launch Options.
   Save any earlier launch option so you can switch back to it.
3. Open Steam and sign in before your first join. Check the player name in
   the Starter, which fills in the last-used Steam persona when available.
   Create or join a lobby and choose a team. Clan Wars opens the game when
   the match is ready. Use Join Game to retry an unsuccessful launch, or Join
   Public CTF from its own panel for public play.

Run without keeping a terminal open
-----------------------------------
Use the terminal for the first launch and for troubleshooting. After setup
works, open the installed launcher in its own session. Use the folder
printed by the installer if it differs from the example.

    launcher="$HOME/Games/Clan Wars Ubuntu Preview 7 r75/Start Clan Wars Ubuntu.sh"
    setsid -f /bin/sh "$launcher" </dev/null >/dev/null 2>&1

You can close the terminal once the launcher opens.

For an app menu shortcut, save this as phoenix-rising.desktop under
${XDG_DATA_HOME:-$HOME/.local/share}/applications (create that folder if
needed). Replace the path in Exec with your full launcher path, keeping
the double quotes.

    [Desktop Entry]
    Type=Application
    Name=Phoenix Rising
    Exec=/bin/sh "/home/you/Games/Clan Wars Ubuntu Preview 7 r75/Start Clan Wars Ubuntu.sh"
    Terminal=false
    Categories=Game;

Open Phoenix Rising from your application menu. For a desktop icon, copy
the file to your desktop and mark it trusted if prompted. This also applies
to other Linux desktops and Steam Deck in Desktop Mode.

If startup fails, run the installed launcher in a terminal for live output.
For a game launch failure, use the log path shown in Starter. With default
paths, look for proton.log in ~/.local/share/ClanWarsUbuntuStarter/joins/
or bridge.log in ~/.local/share/Tribes3CommunityStarter/linux-launches/.
With Steam Snap, game-side logs are under ~/snap/steam/common/.local/share/.

Opening the Starter, browsing matches, and working in a lobby use
native Linux Python. Clicking Join Game asks Steam to start the game, and
can open Steam if it is closed. First-time shader processing can take several
minutes.
Steam Play without a Clan Wars join request runs the ordinary Steam
game command. The Steam launch-option setting belongs to that Steam
game and must be switched manually if another Starter uses it.

Installations with Linux auto-updates enabled check for a signed launcher
update when you open Clan Wars. They keep the existing Steam launch option.
If you already installed Preview 6 r74, close Clan Wars and run the separate
Enable-Clan-Wars-Linux-Auto-Updates.sh once, then reopen Clan Wars. Pass the
install folder as an argument if you installed outside the default folder.

For a headless check of the server connection, run:
    sh "Start Clan Wars Ubuntu.sh" --check-lobby

Use Lobby Browser to spectate a match that allows it, and Armor to choose
and preview the suits available from the server. These controls use the
shared Direct Starter runtime.
